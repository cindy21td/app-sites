Lastgood: Widget Scripts

Run JavaScript code by commit

Your Home Screen widgets run only the last commit whose test run passed, so a widget's script can be edited on the train without breaking the widget. Scripts stay plain JavaScript or TypeScript files in a Git repository you own.

THE SHELF
The first screen is your shelf. Each slot is drawn as the widget it feeds, with its live output, the commit it runs ("e4f5a6b · 6 days clean") and a strip of its test runs: filled for passed, a hollow ring for failed. Back one puts the previous passed commit on the widget in one tap, or press and drag the pin back along the strip.

EDIT, COMMIT, THEN IT MOVES
Edits on the bench are drafts; the widget keeps running its commit. Commit, and Lastgood runs each changed script once with the sample input beside it (sample.json, or a // @sample line at the top). A pass moves that slot to the new commit. A throw or a timeout is recorded with its line, and the widget stays on the last good commit.

YOUR FILES, YOUR GIT
Open a folder in place from Files (iCloud Drive, On My iPhone, another Git app's repository) or clone over HTTPS with a personal access token kept in your Keychain. Line diffs, commit, fast-forward pull and push. Every save writes the plain file where it lives; nothing is kept only inside the app.

WIDGETS AND SHORTCUTS
Small and medium Home Screen widgets, and a "Run shelf script" action that hands your Shortcut's text to the script and gives back its output. Both read the pinned commit, never the draft you're editing.

PULLED CODE WAITS FOR YOU
Commits that arrive by pull never run on their own. Test one on its slot; the shelf moves to it only after it passes on your iPhone and you confirm on its diff.

THE RUNTIME
JavaScriptCore with types stripped from TypeScript on the device. A script gets its input, output (text, a number and unit, rows, a symbol), console, files of its own repository, and fetch to hosts you allow one by one. It can't load code from a URL or build code from text. No script gallery, no downloads, no AI.
